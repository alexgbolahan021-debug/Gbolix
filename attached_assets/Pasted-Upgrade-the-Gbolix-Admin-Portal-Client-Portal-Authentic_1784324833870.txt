Upgrade the Gbolix Admin Portal, Client Portal, Authentication, and User Management into a scalable role-based system suitable for a growing SaaS business.

## IMPORTANT

Do NOT redesign the existing UI or remove any current functionality.

Maintain the existing Gbolix branding, dark theme, animations, colors, responsiveness, routing, and component structure.

Only improve and extend the current system.

---

# 1. IMPLEMENT ROLE-BASED ACCESS CONTROL (RBAC)

Replace the simple Admin/Client logic with four roles:

* Owner
* Admin
* Freelancer
* Client

## OWNER

There should only be one Owner account.

The Owner has unrestricted access to the entire platform.

Owner permissions:

* View every user
* View every project
* View every conversation
* View analytics
* Manage products
* Manage pricing
* Manage services
* Manage wallets
* Manage staff
* Invite staff
* Change user roles
* Promote or demote Admins
* Assign Freelancers
* Delete users
* Platform settings

The Owner can access everything.

---

## ADMIN

Admins manage daily operations.

Admins can:

* Manage clients
* Manage projects
* Reply to conversations
* Upload files
* Change project status
* Create conversations
* Assign freelancers

Admins CANNOT:

* Change Owner role
* Delete Owner
* Change platform settings
* Change billing settings

---

## FREELANCER

Freelancers are internal team members.

They must have their own dashboard.

Freelancers ONLY see:

Dashboard

Assigned Projects

Messages

Files

Profile

Availability

Freelancers CANNOT access:

Users

Analytics

Revenue

Wallet

Products

Platform Settings

Other freelancer projects

Other client conversations

They only work on projects assigned to them.

---

## CLIENT

The Client Portal remains mostly the same.

Clients only access:

Dashboard

My Tasks

Messages

Files

Profile

Products

Wallet (future)
