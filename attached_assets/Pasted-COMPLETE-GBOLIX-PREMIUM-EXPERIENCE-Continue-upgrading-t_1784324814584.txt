ADMIN-INITIATED PROJECT MESSAGING
========================

Create a Project Messaging System for SERVICES ONLY.

Rules:

Messaging must NOT be available for Products.
Messaging must NOT be connected to Credits.
Messaging must only be linked to Service Requests / Projects.

Workflow:

Client submits a service request.
Project is created normally.
Client sees NO chat initially.
In Admin Dashboard, every project has a:
"Start Conversation" button.
Only after admin clicks Start Conversation:
Create conversation thread.
Admin sends first message.
Conversation then becomes visible to client.

Client Experience:

Once conversation exists:

Show floating chat bubble in bottom-right.
Show unread message badge.
Display conversations in:
Dashboard
My Tasks
Project Details

Features:

Permanent message history
Chronological order
Text messages
Image uploads
File uploads
PDF support
DOCX support
ZIP support
JPG support
PNG support

Display:

Sender name
Sender role
Timestamp
Read status

Project Linking:

One conversation per project.
Clients with multiple projects see separate threads.
Admin can switch between project conversations.

Notifications:

Client notified when admin replies.
Admin notified when client replies.
No real-time sockets required.
Refresh loads latest data.

UI:

Modern SaaS messaging UI
Match Gbolix theme
Mobile responsive
Green accent chat bubble
