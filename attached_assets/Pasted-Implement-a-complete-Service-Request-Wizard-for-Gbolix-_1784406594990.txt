Implement a complete Service Request Wizard for Gbolix. This should replace the current generic "Project Name + Description" request form.

## Goal

Gbolix is a premium Digital Operations Studio, not a freelance marketplace. Clients should never see a generic project request form.

Instead, after selecting a service, they should complete a short, guided questionnaire specific to that service. The experience should feel simple, modern, and premium.

Keep the existing dark Gbolix design system, animations, and responsiveness.

# Multi-Step Wizard

Every service request should follow the same structure.

## Step 1

Project Overview

Display a summary card containing:

• Service Name
• Price
• Delivery Time
• What is included
• Estimated completion time for the form (for example: "2 minutes")
• Progress bar

Example

CRM Workflow Automation

Delivery
2–3 Business Days

Price
$79

You'll receive

✓ Fully working automation
✓ Testing completed
✓ Documentation
✓ Revision support

Estimated form time
2 minutes

Do not let the client edit this information.

---

## Step 2

Show service-specific questions.

Only display the questions needed for that service.

Do NOT ask unnecessary questions.

# Submission

After submission:

• Create Project automatically.

• Assign correct service.

• Store every answer in the database.

• Store uploaded files.

• Display all submitted answers inside the Admin Portal.

• The Admin should never need to ask basic questions already answered in the form.

• Clients should be able to view their submitted answers from the Project Details page.

==================================================

# UI Requirements

Use a premium SaaS experience inspired by Linear, Stripe, Notion, Vercel, and Framer.

Include:

• Smooth page transitions
• Progress bar between steps
• Auto-save draft while filling
• Validation before moving to next step
• Animated step transitions
• Success animation after submission
• Mobile responsive
• Accessible form controls
• Green-to-purple Gbolix accent gradients
• Glassmorphism cards where appropriate
• Skeleton loaders while loading forms

The experience should feel effortless. Although different services ask different questions, every request should take only a few minutes to complete and should clearly communicate professionalism and quality.
