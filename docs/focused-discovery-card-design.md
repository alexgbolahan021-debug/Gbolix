# Focused Discovery Assistant Card

The revised homepage integration will no longer embed the Discovery Assistant landing page. The modal will contain only a self-contained conversation card with Gbolix branding, a compact header, a progress rail, the message thread, suggestions, the composer, and the working-picture action.

The visual direction is a dark, premium operations-console card: restrained borders, generous spacing, one bright Gbolix green accent, subtle cyan-violet support accents, and no duplicated hero copy. Desktop layouts use a two-column card with the conversation occupying the main area and a narrow “Discovery path” rail on the right. Mobile layouts collapse to a single conversation column and keep the path as a compact progress strip.

The card opens only after a hero or floating-button click. It closes with an accessible dialog close control and never shows the assistant’s separate landing page. The card will call the existing Discovery Assistant API directly, preserving streaming chat, suggestions, anonymous consent, restart, and structured working-picture analysis.
